# 🎲 Numbers - Sorteador de Números

Segundo desafio do curso de JavaScript da **Rocketseat**.

## 📌 Sobre o Projeto

O **Numbers** é uma aplicação web moderna e intuitiva desenvolvida para realizar sorteios de números aleatórios de forma rápida, personalizável e segura. O usuário pode definir a quantidade de números que deseja sortear, estipular o intervalo mínimo e máximo e optar por não permitir números repetidos na mesma rodada.

A interface conta com um design escuro sofisticado com efeitos visuais de luz ambiente, tipografia moderna e total adaptabilidade para diferentes tamanhos de tela (desktop e mobile).

---

## ✨ Funcionalidades

- **Definição de Quantidade**: Escolha a quantidade de números a serem sorteados de uma vez só.
- **Intervalo Customizado**: Defina os limites mínimo (**DE**) e máximo (**ATÉ**) do sorteio.
- **Prevenção de Repetições**: Opção para alternar se os números sorteados podem se repetir ou devem ser estritamente únicos.
- **Visualização de Resultados**: Exibição dos números sorteados em destaque com identificador de rodada.
- **Sortear Novamente**: Ação rápida para reiniciar o formulário ou realizar uma nova rodada.
- **Perguntas Frequentes (FAQ)**: Seção explicativa sobre as regras e o algoritmo de sorteio.
- **Design Moderno e Responsivo**: Layout construído com tema escuro, brilho ambiente (*ambient glow*) e responsividade para dispositivos móveis.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura semântica e acessível.
- **CSS3**: Layout moderno com Flexbox/Grid, variáveis CSS, gradientes e efeitos de luz.
- **JavaScript (Vanilla)**: Manipulação do DOM e lógica de geração aleatória de números.
- **Google Fonts**: Tipografias *Roboto Flex*, *Roboto Mono* e *Sora*.
